Octopus

『Vampire Survivors』系の遊びをベースに、レベルアップ時の選択で戦い方が広がる構成を目指しています。 通常弾・周回弾・ドローンを個別に強化できるようにし、シーン遷移後の結果反映まで含めて ひとつの流れとして扱えるように実装しています。

C++ DirectX KamataEngine 個人制作 拡張重視設計
  • 開始演出、一時停止、レベルアップ、死亡、リザルト遷移を分離して管理
  • 攻撃種類ごとに追加・強化処理を独立させ、成長要素を後から増やしやすく設計
  • プレイヤー追従の 3x3 グリッド床で広いフィールド感を保ちながら描画を整理
タイトル UI もプロジェクト内のアセットからそのまま使用。 一枚のシートの中で、作品名とゲームの雰囲気が最初に伝わる構成にしています。

成長要素の拡張性

PlayerManager 側で通常弾・周回弾・ドローンの管理を分け、 レベルアップ時の選択肢から個別に強化できる構成にしています。 攻撃の追加と強化の両方を段階的に実装しやすい点を重視しました。

  • 通常弾の発射間隔短縮
  • 周回弾の追加と個数増加
  • ドローン攻撃の追加と頻度強化
